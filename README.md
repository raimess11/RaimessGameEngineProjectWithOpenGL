# Detailed Version (Portfolio / Documentation Quality)

Raimess Game Engine Project with OpenGL — Experimental Engine Development (Started 06/2024)
An experimental game engine built from scratch to explore the underlying architecture of real game engines. This first prototype implements essential engine components, including:

* **OpenGL-based render pipeline** capable of rendering background frames
* **Game environment system** to manage core engine states
* **Game logic container** for organizing and executing gameplay behavior
* **Event handling system** for user input and engine-level events

Although early in development, the project provides a functional foundation for rendering, logic flow, and system communication, serving as a hands-on learning platform for engine design.
